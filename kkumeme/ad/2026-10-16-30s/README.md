- 기존 크림 #FFF9EE, 보라 #493165, 노랑 #FFE483, 점무늬 바탕·폰 목업·검은고딕 제목과 노랑 밑줄·개구체 손글씨·스티커가 톡 붙는 움직임을 재사용했습니다.
- 개구체 문자에 섞이던 기존 꽃/파도/노을 이모지를 제거했습니다. 새로운 편지·컵·꽃·지도는 코드로 직접 그린 SVG이며 외부 사진·로고·이미지·새 폰트가 없습니다. 꾸밈 자체 로고와 기존 직접 그린 바다 그림은 15초판 자산을 그대로 씁니다.
- 달력: 실제 `CalendarWidget`, `calendar-themes.ts` 및 CSS의 페이퍼 테마를 참고한 광고용 HTML입니다. 2026년 10월·일요일 시작·날짜 위쪽·일요일/공휴일 빨강·토요일 파랑(공휴일 빨강 우선)을 적용했습니다. 3일 개천절, 5일 대체공휴일, 9일 한글날은 레포 공휴일 표 기준입니다. 이번 장면은 6종 중 페이퍼 한 종류만 보여줍니다. 달 넘기기·날짜 자동 배치 기능을 표현하지 않습니다.
- 지도: 서울 산책이라는 꾸미기 주제 아래 직접 그린 **도식적 그림**입니다. 「그림 지도 예시」를 화면 안에 표기합니다. 실제 지리·가게·경로·주소가 아닙니다. 방문자의 지도 이동/확대·길찾기·장소 검색·GPS·좌표 자동 고정은 표현하지 않습니다. 실제 서비스의 지역은 서울·부산·제주이며 장면에 선택 UI를 새로 만들어 넣지 않았습니다.
- 두 장면의 스티커는 일반 요소를 손으로 얹는 표현입니다. 달력 날짜·지도 좌표에 연결되는 기능으로 보여주지 않습니다.
- 기능 사실 출처: kkumeme AGENTS.md 「달력 위젯」「지도 위젯」. 새 장면의 렌더 대체 선택은 Chromium 실행 불가에 따른 지시서의 허용 경로입니다.

## 소스 (`src/`)
- `index.html`: 원본 15초 장면. `window.baseRender(t)`로 유지하고 `scenes.js`가 30초 시계로 재배치합니다. 540×960 CSS, DPR 2 → 1080×1920.
- `scenes.js`, `scenes.css`: 달력·그림 지도 장면. `window.render(t)`는 0~30초 어디든 직접 이동할 수 있습니다. 날짜/프레임은 고정이며 wall clock·랜덤값을 사용하지 않습니다.
- `render.cjs`: 로컬 정적 서버 → 900프레임 → 대표 컷7개/board → ffmpeg 인코딩 → ffprobe 확인. 브라우저 오류/404/외부 요청을 허용하지 않습니다. 정상 종료·실패 모두 브라우저와 서버를 닫습니다.
- `tools/prepare.cjs`: 기존 kkumeme의 `app/fonts.css`·`public/fonts`를 이 소스 폴더로 복사하고 원본 우표 녹화를 `rf5/f000.png`~`f149.png`로 풉니다. **-start_number 0** 지정(원본 프레임 주소와 일치).
- `tools/check.cjs`: 브라우저 없는 로직 검증. 900시점·7개 역순 재진입·달력31일·이모지 혼입 검사. 화면/폰트/영상 검증은 아닙니다.
- `tools/frames.cjs`, `tools/entry.tsx`: 원본 15초판의 실제 UI 녹화 방법을 보존한 참고 자료. 기존 esbuild 단독 번들·빌드 CSS·Playwright clock 고정 절차용이며, 이번 새 장면에서는 실행하지 않았습니다. `entry.tsx`의 로컬 import 경로와 frames.cjs의 서버/사진 경로는 해당 서버 환경에 맞춰야 합니다.
- `photo.jpg`, `stamp.png`, `icon.svg`, `logo.svg`, `rec-stamp-maker.mp4`: 기준 커밋의 같은 Git blob 재사용. `rec-stamp-maker.mp4`는 입력 소재(5초)이며 최종 30초 MP4가 아닙니다.

필요 도구: Node, 기존 Playwright+Chromium, ffmpeg/ffprobe, kkumeme checkout. 이 작업용 스크립트는 패키지를 설치하지 않습니다.

```bash
cd /path/to/devrocket-media/kkumeme/ad/2026-10-16-30s
node src/tools/prepare.cjs /root/kkumeme
node src/tools/check.cjs
node src/render.cjs
```
