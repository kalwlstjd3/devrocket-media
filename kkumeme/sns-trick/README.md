# 꾸밈 SNS 반전 트릭 이미지

네 이미지는 모두 **AI 생성**이다. 위에서 90°로 내려다보는 구도와 왼쪽 위 자연광을 기준으로 배경과 물건 단독 컷을 맞췄다. 배경은 1080×1890 PNG, 단독 컷은 900×900 PNG이다.

| 파일 | 프롬프트 요약 |
| --- | --- |
| `a-bg.png` | 따뜻한 나무 카페 테이블, 우상단에 일부만 보이는 라떼, 가운데 비어 있는 무광 흰 접시. 접시의 중앙은 흰 스티커 테두리가 묻히도록 밝고 균일하게. |
| `a-item.png` | 순백 배경 위 분홍 라즈베리 마카롱 하나를 수직으로 촬영한 모습. 자연스러운 표면과 옅은 접촉 그림자. |
| `b-bg.png` | 밝은 나무 책상 위 빈 흰 종이 한 장, 우상단 가장자리에 연필 끝. 종이는 글과 줄이 없는 밝은 흰색. |
| `b-item.png` | 순백 배경 위 잎이 붙은 빨간 딸기 하나. 잎은 왼쪽 위, 딸기 끝은 오른쪽 아래를 향하고 그림자는 옅게. |

## 합성 시작점

아래 좌표는 배경 원본의 좌상단을 기준으로 한 물건의 중심이다. 크기는 배경을 제거한 물건 기준이다.

| 세트 | 중심 (x, y) | 권장 시작 크기 |
| --- | --- | --- |
| A | (535, 940) | 마카롱 지름 180~200px |
| B | (540, 940) | 딸기 긴 변 185~215px |

꾸밈의 「스티커 만들기」에서 물건만 선택하고, 짧은 변의 3.5%로 생성되는 흰 테두리가 접시 또는 종이의 평평하고 밝은 영역에 완전히 들어오도록 배치한다. 단독 컷은 순백 배경의 PNG이며 편집기에서 배경을 제거한 후 사용한다.
